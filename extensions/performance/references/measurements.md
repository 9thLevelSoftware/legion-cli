# Performance measurements

- Startup: cold and warm samples when the harness distinguishes them.
- Interaction: one named user action with a stable start and completion signal.
- Resources: transferred bytes, loaded module count, or bundle sizes from project tooling.
- Memory: resident or heap measurement at idle and after the representative action.
- Baselines: identify the exact configured threshold and report the observed delta.
- Evidence: include command, sample count, units, environment, and raw artifact path.
