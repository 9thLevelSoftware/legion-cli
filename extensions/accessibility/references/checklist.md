# Accessibility checklist

- Run the repository's configured axe checks against each reachable primary screen.
- Capture keyboard traversal order and any traps.
- Verify a visible focus indicator on interactive controls.
- Verify dialogs move focus in, retain it, and restore it on close.
- Record accessible names, headings, landmarks, errors, and live announcements.
- Mark color, zoom, screen-reader, or human judgment checks unavailable until observed.
