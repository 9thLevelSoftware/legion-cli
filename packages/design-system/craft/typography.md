# Typography

Brand-agnostic type rules. A design-system package may override faces and scale; craft covers the rest.

- Prefer a small scale (body, one display, one caption). Do not invent a fifth size to fill a mockup.
- Body line-height ≥ 1.4. Do not shrink text to fit a box.
- Headings are sentences, not Title Case Marketing.
- Use the system UI stack until a package names a face. Do not load a display font “for vibe.”
- Tabular numbers for counts, times, and money.
